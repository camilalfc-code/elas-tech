## 📚 Conteúdos praticados

| Tema | O que eu pratiquei |
|------|--------------------|
| **Concatenação** | Juntar textos e valores com `+` |
| **Operadores** | Operadores aritméticos e relacionais |
| **Estruturas de decisão** | `if`, `else` |
| **Estruturas de repetição** | Laços com `for` |
| **Strings** | `length()`, `toUpperCase()`, `toLowerCase()`, `charAt()`, `contains()`, `equalsIgnoreCase()`, `trim()` |
| **Arrays** | `int[]` e `String[]`, percorrer com `for`, soma e média, ordem inversa |
| **Métodos** | `void` e `return`, parâmetros, `static`, assinatura e sobrecarga (*overloading*) |

---

## 🧩 Destaque: Atividade de Métodos

Os 7 exercícios de métodos estão organizados em classes separadas dentro de `AulaMetodo`:

- **Utilidades1:** método que devolve o dobro de um número
- **Utilidades4:** método que calcula a média de duas notas
- **Utilidades5:** método que verifica se a pessoa é maior de idade (`boolean`)
- **Utilidades6:** sobrecarga do método `somar` (dois inteiros, três inteiros e dois decimais)
- **Utilidades7:** sobrecarga do método `saudacao` (com e sem parâmetro)

## ▶️ Como executar

1. Clone este repositório
2. Abra o projeto no **IntelliJ IDEA**
3. Use o **JDK** configurado no projeto
4. Execute a classe `Main` (ou a classe do conteúdo que quiser testar)
